1. THE VIEW ("D5" = the nx3 lag view + equal depth)
   slot = MSK day - Sep 6. Dense slots = hz2_common.DENSE_SLOTS = 0..8, 11, 12, 13 (slots 9, 10, 14 hold 76 feeds; never a source).
   window(cut) = the LAST 5 DENSE SLOTS below cut. One rule for every row of every split:
     train rows (holdout + pool feeds only; no full-train build): has = slot >= 6, cut' = max(slot - L, 5) exactly as nx3
        (nn_x/w12/nx3/out/raw/train_cut_feed.npy, re-derived here from hz2_lag.npy); sources = train feeds of window(cut').
     val / test rows, natural: cut = 14 -> window = slots 7, 8, 11, 12, 13.
     val rows, stale-val twin: cut = slot - L (nn_x/w12/nx3/out/raw/val_twin_cut_feed.npy, re-derived from hz2_common.assign_lags) -> window(cut), cuts 7..12.
   Differences to the nx3 lag view: (i) depth is 5 dense source days for EVERY row (nx3: 5-7 on train rows, 12 on val / test rows);
   (ii) no sparse members (label statistics cannot have them on val / test rows; label-free pieces drop them for one rule).
   What is equal by construction: the number of source days, the rule that picks them, the lag rule of nx3. What is NOT equal by construction
   and is therefore gated: traffic per source day, the two empty days inside the val / test window, the feed mix, weekday.
   Label statistics: sources are train feeds of the window that are not holdout feeds; the window ends before the cut, the cut is <= the row's slot - 1,
   so no label of the row's own feed, no later snapshot of anyone, no val / test label can enter. Rows with slot < 6 have no view (has = 0).

3. GATES (form of nn_x/w12/nx3/nx3_gates.py; bars unchanged)
   G-parity, label-free, read first:
     C3 non-default share by the 7 listing-age buckets: test-like train rows (POOL feeds = p_random > 0.5, M >= 50, not holdout, slots 11-13) against
        PRIVATE and against PUBLIC rows (test feeds with M >= 50); val-like (slots 6-8) against val rows (M >= 50): dZ <= 0.05, largest bucket <= 0.10.
        The same on the holdout feeds is printed. Non-default = seen (P1), impression in the window (P2, P5), n_s1 + n_s2 > 0 (P4), value present (P6, P7);
        P3 has no default value: its C3 is the share of rows with kn1_5 above the natural-val median (stated as a substitute).
     C4 PSI <= 0.25 of every entered form, pool has = 1 rows against val / public / private (10 val deciles of the non-zero values + an exact-zero bin).
     C5 non-default share on every test day >= 0.5 x val's largest (overall / slot 16 / slot 18).
   G-info: score test of condlib.Null, null model = pool + the control block of the ranker's own inputs + nx_rp3_z + nx_rp3_rk
        (holdout: the lag-view values of nn_x/w12/nx3/out/files/train, NaN -> 0; val: data/feats/val = natural, as the task orders; the same read with
        the nx3 stale-val twin in the null model is printed), so a pass means information beyond nx3.
     Witness H = holdout rows of the 15,225 lag-view feeds (pool = 16 held-out wide students). Witness T = val rows with the stale-val twin of the column (TO16).
     A column-form PASSES if it has the sign on record and |cz| >= 2.5 on H AND on T, and its |cz| on each witness exceeds every placebo of that witness.
     Placebo: 20 within-feed permutations of each piece's first z column per witness (>= 140 draws per witness); sd and maximum are printed, and the
     threshold is restated as 2.5 x max(1, placebo sd).
     Family-wise false pass under independence of the two witnesses: 21 x P(|z| >= 2.5)^2 / 2 = 21 x 0.0124^2 / 2 = 0.0016.
   VERDICT per piece: SURVIVES = G-parity ok and a column-form passes G-info. INFORMATION WITHOUT PARITY = G-info passes, G-parity fails.
     NOT SHOWN = G-info fails (with the witness that failed). STOPPED = no rebuild can exist (reason given).
   Nothing is re-binned, re-transformed or re-lagged after a read. Every look is counted in the report.
