THE SIX CONSTRUCTIONS (priority order of the task: a, a, a/c, b, b, c)
 N1 cw_item  (a: item -> cell -> item smoothing of the walk; covers cold candidates). For candidate c with cell g: over the latest 500 admitted postings of CELL g
             whose event is not item c, each distinct sequence s adds  sum_{events x of s, cell(x) != g} wd(x) / len(s),  wd(x) = max 0.95^hpos over the row's
             history occurrences of ITEM x / deg_item(x).  Value = total / (number of distinct sequences + 10).
 N2 cw_cell  (a: user history -> cell -> sequences -> cell -> candidate; attribute-level RP3 at fine resolution). Same scan; the seed is matched through cells:
             sum_{events x of s, cell(x) >= 0, cell(x) != g} wdc(cell(x)) / len(s),  wdc(a) = max 0.95^hpos over the row's history events in cell a / deg_cell(a).
             Value = total / (number of distinct sequences + 10).
 N3 aud_cell (a + c: audience of the candidate's cell). Over the same distinct admitted sequences of cell g (event not item c): mean cosine between the row's user
             vector and the sequence owner's user vector (both centred by the mean train user vector, then L2-normalised). Value = sum cos / (n + 5).
 N4 fwd20    (b: forward-only transition, item level). For candidate c: over the distinct admitted sequences that hold c (latest 500 postings), for every
             occurrence of c at index p (sequences are newest first) and d = 1..20: x = event at p + d (OLDER than c, i.e. x was followed by c within 20 steps);
             adds w0(x) / d, w0(x) = max 0.95^hpos of ITEM x in the row's history. Value = total (the directional half of the windowed input seq_cv_invd20).
             The backward half is computed as a diagnostic only (kernel check against the stored seq_cv_invd20); it is not a construction and gets no cz.
 N5 rp3_l8   (b: the walk of record seeded with the newest 8 history events only). Kernel of record c9.rp3 unchanged, history weights 0.95^hpos for hpos < 8 and
             0 for hpos >= 8; value = rp3b05.
 N6 aud_item (c: audience similarity, item level). Over the distinct admitted sequences that hold item c (latest 500 postings): mean cosine between the row's user
             vector and the owner's user vector, centred / normalised as in N3. Value = sum cos / (n + 5).
 Entered forms of every construction, fixed now: z = within-feed z over all candidates (N1, N2, N4, N5: of log1p(K x), K = 1 / median non-zero value on natural
 val rows; N3, N6: of the raw value), clipped to +-5, 0 on a flat feed; rk = within-feed mid-rank percentile - 0.5 (lens.feed_z / feed_rk). A row without a value is 0.

GATES (form of nn_x/w12/nx3/nx3_gates.py; the train side is the HOLDOUT feeds because no full-train array is built: the critic's population)
 C3  non-zero share by the 7 listing-age buckets: holdout slots 11-13 vs PRIVATE and vs PUBLIC rows (test feeds with M >= 50), holdout slots 6-8 vs val rows
     (M >= 50): dZ <= 0.05 and largest bucket (row share >= 0.05) <= 0.10.
 C4  PSI <= 0.25 of each entered form, holdout has = 1 rows vs val / public / private; bins = 10 val deciles of the non-zero file values + one bin for exact zero.
 C5  non-zero share on every test day >= 0.5 x val's (largest of val overall / slot 16 / slot 18).
 cz  score test of condlib.Null with null model = pool score + the lens's control block of the ranker's own inputs + nx3 (nx_rp3_z, nx_rp3_rk: the installed
     lag-view files on holdout rows, the stale-val twin files on val rows). Witness H = holdout rows, lag view (pool = 16 held-out wide students; 0 on the 14,775
     feeds without the view). Witness V = val rows with the STALE-VAL TWIN of the column (base TO16; base FILE printed). Natural val is printed, not a gate.
 Placebo: for every construction 5 within-feed permutations of its z column on each witness (30 per witness, seeds 7000+ / 8000+), sd and max |cz| printed.
 PASS of a construction = parity C3 + C4 + C5 ok AND the same form (z or rk) has the same sign and |cz| >= 2.5 on BOTH witnesses, AND the placebo block of that
     witness has max |cz| < 3.0 (if a placebo sd is outside 0.8-1.2 the threshold is scaled by it and that is stated). 12 forms x 2 witnesses are read; under
     "nothing new" the chance that any form passes both is about 12 x 2 x 0.0062^2 = 0.001.
 Cold rows: cz of each column set to 0 outside the rows whose item has NO admitted item-level posting in the row's own view (the walk is silent there by
     construction), on both witnesses; reported, not a gate. Warm-row complement reported too.
 A PASS here is a candidate for a build of record + a trained arm, nothing more. "Nothing" is an acceptable result.
