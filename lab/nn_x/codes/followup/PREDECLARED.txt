TASK 1: s4 SIMILAR-LISTINGS ITEM-TO-ITEM GRAPH
- Edges from ALL 3,151,208 train feeds' histories (no sampling; if memory forces it, a seeded uniform feed sample, stated).
  For every history event with type e1 and source s4 (view of item B from the similar-listings block), the anchor A = the
  nearest OLDER (higher hpos) e1 event in the same history snapshot with item != B (any source). Dedupe per user:
  unique (user, A, B), user_id 0 feeds each a separate user; edge weight c(A->B) = number of distinct users; first_day(user,
  A, B) = min MSK day ((ts + 10800) // 86400) of that user's feeds whose snapshot contains the pair.
- Val features: edges from all train feeds (all train days < val days: no leak, no val/test histories used).
  Holdout features: only (user, A, B) with first_day < the holdout feed's day (strictly earlier days; no leak).
- Features (per candidate B of a feed; R = the 32 newest distinct items with an e1 event in the feed's history):
  s4_link (PRIMARY)  = max over A in R of c(A->B) / out(A), out(A) = sum_B' c(A->B')   (0 if none)
  s4_link_any        = 1[some item A anywhere in the feed's history (any event type) has c(A->B) > 0]
  s4_sym             = max over A in R of (c(A->B) + c(B->A)) / (out(A) + in(A))
  s4_sum             = log1p(sum over A in R of c(A->B))
- GATE (per feature): PASS iff val nested delta > +0.0003 AND > 2 SE (z > 2) AND tail win rate > 0.5 (point estimate).
  Multiplicity: s4_link is the primary (z > 2); s4_link_any / s4_sym / s4_sum count only with z > 2.5.
  Task-1 verdict = PASS iff at least one feature passes; else CLOSED. Holdout nested delta reported; if a passing feature has
  holdout delta < -2 SE the verdict becomes HOLD (val-only, contradicted). Buried-cell pair AUC reported (information).

TASK 2: REGION-NORMALISED POPULARITY
- Region key: K2 components (nn_x/codes/features/out/k2_item_comp.npy, frequent items in components >= 10 items). A feed's home
  region R_f = the component winning the majority vote among the feed's candidates at the feed's modal non-zero f2 level
  (04_k2_geo.py (b) construction; ties -> larger count then lower comp id); feeds without a voter have no region.
- Counts from ALL train feeds' histories: unique (user, region, item) over history events of ANY type (user-0 feeds separate
  users; region = R_f of the snapshot's feed; feeds without a region contribute to the global count only), with first_day as in
  task 1. n_i = distinct users with item i; n_iR = distinct users of home region R with item i; N_R = sum_i n_iR; N = sum over
  region-assigned pairs; pi_R = N_R / N.
- Features for candidate i in feed f with home region R = R_f:
  rp_lift (PRIMARY) = log( ((n_iR + m * pi_R) / (n_i^reg + m)) / pi_R ), m = 5, n_i^reg = users with item i that HAVE a region
                      (regional over-/under-representation of the item among the user's region vs all regions; 0 = neutral)
  rp_cnt            = log1p(n_iR)  (popularity within the user's region class)
  Feeds without a region: both features constant 0 within the feed (fz -> 0, i.e. no effect).
  Holdout: counts with first_day < the holdout feed's day. Val: all train.
- GATE identical to task 1: PASS iff val nested > +0.0003 AND z > 2 (rp_lift; rp_cnt needs z > 2.5) AND tail win rate > 0.5;
  else CLOSED; holdout < -2 SE on a passing feature -> HOLD.
