BANK (label source; train labels only)
- train feeds with p_random > 0.5 (eda/labels_position/out/train_prandom.npz; NaN -> 0; M < 50 -> 0) and M >= 50.
- excluded: the 30K holdout feeds (rng 12345 rule of nn_x/r6/train.py); user_id 0; every user_id that appears in val,

- data days = MSK calendar days with >= 1000 train feeds: day idx 0-8 (Sep 6-14) and 11-13 (Sep 17-19).
- FIXED-LENGTH trailing window: for a query on day D the bank is the 5 most recent data days d with d <= D - 3
  (gap >= 3 calendar days, = val's minimum gap Sep 19 -> Sep 22).
  val (D = Sep 22 / Sep 24) -> {Sep 13, 14, 17, 18, 19}; holdout D = Sep 13 -> {Sep 6-10}; Sep 14 -> {Sep 7-11};

- one bank entry per user: key = L2-normalised mean of the L2-normalised int8 user_emb of the user's in-window bank feeds;
  value = all shown candidates of those feeds (item_id, cl4096 code from data/clu_work/cand_cl_4096_train.npy, cand_target).
- no subsampling unless the runtime forces it (then stated in the report).

QUERY / NEIGHBOURS
- query key = the feed's own user_emb (val: data/flat/val/user_emb.npy; holdout: its train row), L2-normalised.
- k = 32 nearest bank users by cosine (exact numpy matmul); weights w_j = softmax(10 * cos_j) over the 32.

SIGNALS per candidate c (key X(c) = item_id or cl4096 code; code < 0 -> no cluster evidence)
- s_pos_X    = sum_j w_j * 1[neighbour j clicked >= 1 shown item with key X(c)]
- s_neg_X    = sum_j w_j * 1[neighbour j was shown >= 1 item with key X(c) and clicked none of them]  (shown-but-ignored)
- contrast_X = s_pos_X - s_neg_X
- X in {item, cl4096} -> 6 signals.
- PRIMARY (gated) arms: s_neg_item, contrast_item, s_neg_cl, contrast_cl (4 arms; the plan's distinct-mechanism signals).
- SECONDARY (reported, never gated): s_pos_item, s_pos_cl, and JOINT = nested ridge direction over z(s_pos_item, s_neg_item,
  s_pos_cl, s_neg_cl) (ridge alpha 1.0 on within-feed-demeaned labels, fitted on the 4/5 training users together with z(G3)).

COVERAGE: share of candidates with any neighbour evidence (s_pos + s_neg > 0), item and cl4096 level, val and holdout,
  ratio estimate with feed-clustered SE.
