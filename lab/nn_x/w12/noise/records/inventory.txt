NEVER TRIED (why)
1. Truncated, symmetric or GCE losses on students: prior 0.02, and the planned CPU zoo arms never ran (F452).
2. Confident learning or co-teaching (drop/relabel clicks the teacher finds unlikely): not catalogued. kdc, robust and the redraw test say those clicks are signal.
3. IPS or learned-propensity unbiased LTR on the real network: CPU proxy only.
4. Full run with the corrected short-feed p_random: stopped at 40 min.
5. Label spreading over near-copy groups: not run (co-click proxy hurt).
6. Label smoothing on students: smoothing ran only on click-label proxies.
7. Clean function matching: only a flawed form ran (F574).
8. Size of the hidden display-position noise in test (holdout oracle with positions): never measured.
9. Within-category production order as aux teacher: the probe killed it (F536).

Bottom line: distillation was the one denoising step that paid. The other label-side steps stayed within noise or hurt, and the redraw test says the leftover per-feed misses are the draw, not noise anyone can fix. Item 4 is the one open lever that looks like a fix. Item 3's proxy read negative. Item 8 would only size the floor.
