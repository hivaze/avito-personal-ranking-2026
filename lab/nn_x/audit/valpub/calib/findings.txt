5. PRE-REGISTERED RULE (stated for future use; the numbers in it were fixed on 2026-11-13 and are not re-fitted per candidate)
---------------------------------------------------------------------------------------------------------------------
   For a new candidate C vs the current pick G3, before any public look: H_C = holdout paired delta (train-only pool, SE_h);
   V_C = uniform val delta (SE_v); V'_C = M x cold x hour5 private-weighted val delta. E_C = H_C + 0.15 V'_C.
   Pick-1 switch: H_C >= +1 SE_h AND E_C > 0 AND V_C >= -1 SE_v AND presub PASS; among qualifiers the highest E_C.
   Public readout of C = verification against the pre-stated expectation r_C ~ H_C: |r_C - H_C| > 2.5 sqrt(SE_pub^2 + SE_h^2)
   declares the holdout lens broken for that candidate class and reverts to "G3 stays". Candidates without a train-only form
   (stackers, FT-only files, overlays, w_ft variants) have no H_C: not eligible for pick 1; pick 2 only if r_C >= -1 SE_pub.
   Val remains a gate (no slice < -2 SE, pmix >= -1 SE), never the ranking criterion between near-copies. This rule would have
   kept G3 at every decision point of 11-12 and would not have spent public slots on M2 / S2 / TOonly readouts.
