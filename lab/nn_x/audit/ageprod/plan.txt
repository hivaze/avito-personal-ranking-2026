HARNESS (identical to the TRUNC fresh-sample replication nn_x/insights/review/r2_trunc_replicate.py)
- Train sample: U2 = 150K train feeds (seed 2026, disjoint from data_usage's U, natural mix, holdout excluded),
  nn_x/insights/review/out/gb/U2_{X,meta}. Features: the 53 leak-free GBDT features of 06_gbdt_cache.py.

  feature/bagging fraction 0.8, lambda_l2 10, max_bin 255, 400 rounds, 12 threads; seeds 11, 12, 13, 14 (the r2 seeds).
- Readouts: val (data_usage val cache, 14,423 feeds, exact metric) and HO (10K train-period random-like M>=50 holdout

- base and tprod1 are RE-RUN by the new script (same seeds/params) so that all arms come from one code path; the

AGE MARGIN (training-only additive logit offset, init_score, production rows only)
- age = time since the listing first appeared = age_hours(f4) with data/feats/life_f4_age_knots.npy, EXACTLY as
  a06/a07/a08: u = f4*64, k = clip(floor(u), 1, 62), linear interpolation between knots[k] and knots[k+1];
  f4 >= 63/64 - 1e-6 -> NaN -> treated as 1e8 h (last bin), as a08 does.
- 8 bins (a08 edges, hours): [0,3) [3,12) [12,24) [24,72) [72,336) [336,2160) [2160,8760) [8760,inf).
- L[b] = log( (rate_prod[b] / base_prod) / (rate_expl[b] / base_expl) ), unweighted positive rates over candidate
  rows of the FULL train set (holdout feeds excluded): production = cls 0 of data_usage out/train_feeds.parquet
  (NN p_random <= 0.5, which includes every M<50 feed), exploration-like = cls 1 (p_random > 0.5, M>=50 only).
  Production lifts are computed per M bucket (M<50, M>=50) against the single M>=50 exploration reference (no
  exploration reference exists for M<50: the NN rule forces p_random = 0 there). Counts, rates, lifts and SEs are
  reported (ap01), plus the a08 definition (p>0.9 vs p<0.05, M>=50) and the lifts on the U2 sample as checks.
- Applied: init[row] += a * L[M bucket of the feed, age bin of the row] for every row of a production (cls 0) feed;
  0 on exploration-like rows; never at inference (val / HO / stale predictions are f(x)).

ARMS (all four seeds each)
  base | age1 (a = 1) | tprod1 (r2's truncation offset: per-group rkend 0-2 lifts estimated on U2, production rows
  only) | tprod1+age1 (sum of both offsets).
  Secondary, reported, not gating: ageh1 (age offset on M>=50 production rows only), age0.5 (a = 0.5).
