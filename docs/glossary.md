# Glossary

In brief: one alphabetical table of the plain terms that the pages in `docs/` and the package `avito_ranker/` use, and of the code names that files and run names in `lab/` carry. Each row gives the meaning and where to read more. Scores are NDCG on a named split, and SE is one paired standard error over feeds.

Names in code type come from the lab, and stored artefacts are still named after them. A reader of the pages under `docs/` needs the rows in plain type; the rows in code type matter when reading files under `lab/` and `experiments/`. The ordering ignores symbols such as the backtick, `@` and `_`.

"Where" first gives the page that defines or explains the term, then the research line under `experiments/`, the package module or the record that holds it. A number such as [03](03-solution.md) stands for the page of that number in `docs/`.
