# Evidence index

In brief:

- This page maps each headline number of [06-what-worked.md](06-what-worked.md) and of the twenty failures in [07-what-failed.md](07-what-failed.md) to a published file that holds it.
- Of the 38 rows, 34 trace in full to a published file and 4 in part. No row rests only on unpublished records.
- The files are text print-outs of evaluation scripts, small CSV and JSON data files and per-run logs. For 10 rows the number or its standard error is published only in a report written during the work.
- The full catalogue of 312 ideas is in [catalogue.csv](catalogue.csv), one row per idea.

## Conventions

- A path starts at the repository root. The row, key or line named after it says where in the file to look.
- "Computed" means that the file holds the two values and the page prints their difference. "Unrounded" gives the digits of the file where the page rounds.
- In the column "Traced", "full" means that the whole headline number is in the cited files. "Part" means that some of it is only in a working record.
- The working records (the decision ledger, the status log, the experiment registry, the coverage map and the freeze protocol) are cited by name in the docs and are not published.
- The predictions per candidate are not published either. A paired standard error (SE) can therefore be read in a file, and it cannot be recomputed.
- Every file below was opened on 20 November 2026 and the number was seen in it. Scores, splits and notation follow [04-validation.md](04-validation.md) and the [glossary](glossary.md).

## What cannot be traced

No row rests only on unpublished records. Four rows rest on them in part:

- Change 17: the standard error ± 0.00024 of the validation difference. The decision ledger holds it.
- Change 18: the standard error ± 0.00036 of the validation difference. The decision ledger holds it.
- Failure 8: the pooled z of -1.95 and -2.31. The two reads are published only as copies of the ledger: a summary row for weight decay 0 and a quotation in a planning report for 0.05.
- Failure 9: the holdout part, -0.00029 ± 0.00026, and the pooled z of -1.51 of the 8-seed read.

For ten full rows the number or its SE is published only in a report written during the work. They are changes 1, 5, 6, 9, 11, 13 and 14 and failures 2, 6 and 10. No script print-out of these numbers was found in the published tree.

Two full rows cite a summary file whose own source column names the decision ledger: the validation number of failure 18 and the public pair of failure 20. A second published file holds the levels behind both. The SE of failure 18 is in the summary file only.

## The catalogue as a table

The catalogue of [07-what-failed.md](07-what-failed.md) is also published as `docs/catalogue.csv`: 312 rows, one per idea, in the order of the page. Its columns are the theme, the four cells of the row as plain text, the target of a link in the "Where" cell and the outcome class. `scripts/export_catalogue.py` writes it from the page with the parser of `scripts/figures/count_catalogue.py`, and checks its counts per theme against that parser.
