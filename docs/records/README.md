# Stored gate outputs

`gate-outputs/` holds the text that the pre-submission gate printed for five files ([10-reproduce.md](../10-reproduce.md#what-to-expect)). `scripts/09_check_submission.py` and `scripts/freeze_check.py` compare a new gate run with these files.

The working records of the project (the decision ledger, the status log, the experiment registry, the coverage map, the freeze protocol and the picks audit of 16 November) are cited by name in the docs. They are not published.
